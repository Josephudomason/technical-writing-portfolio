# Getting Started With NovaBank

> NovaBank is a fictional banking application used for portfolio documentation. It is not a real bank, financial institution, or regulated product.

## Create an Account

1. Open NovaBank.
2. Select **Create account**.
3. Enter your legal name, email address, phone number, and password.
4. Review the verification prompt.
5. Submit the form.

## Log In

Enter your email address and password. If two-factor authentication is enabled, enter the verification code from your configured method.

## Reset a Password

1. Select **Forgot password?** on the login screen.
2. Enter the email address connected to the account.
3. Follow the reset link.
4. Create a new password.
5. Log in again with the new password.

## Common Issues

- If the reset email does not arrive, check spam and confirm the email address.
- If the verification code expires, request a new one.
- For more help, see [Troubleshooting](troubleshooting.md).
