# Profile Settings

> NovaBank is a fictional banking application used for portfolio documentation. It is not a real bank, financial institution, or regulated product.

## View Profile

Open **Profile** to review your name, email address, phone number, mailing address, and notification preferences.

## Update Contact Information

Some updates may require verification. NovaBank may ask for a one-time code before saving a new email address or phone number.

## Communication Preferences

Users can manage product updates, transaction alerts, security alerts, and statement notifications. Security-critical notifications cannot be fully disabled.
