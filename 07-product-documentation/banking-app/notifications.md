# Notifications

> NovaBank is a fictional banking application used for portfolio documentation. It is not a real bank, financial institution, or regulated product.

## Notification Types

| Type | Purpose |
| --- | --- |
| Security alerts | Login, password, device, and verification events |
| Transaction alerts | Deposits, withdrawals, card activity, and transfers |
| Account alerts | Low balance, statement availability, and account status |
| Product messages | Feature updates and service announcements |

## Manage Notifications

Open **Profile > Notifications** and choose which channels to use for each notification type. Available channels may include push, email, and SMS.

## Delivery Problems

If alerts do not arrive, confirm that contact information is current, app notifications are enabled, and messages are not blocked by the device or email provider.
