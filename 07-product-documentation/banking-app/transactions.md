# Transactions

> NovaBank is a fictional banking application used for portfolio documentation. It is not a real bank, financial institution, or regulated product.

## View Transaction History

Open **Transactions** to see recent deposits, withdrawals, card purchases, fees, and transfers. Use filters to narrow by date, amount, category, or account.

## Transaction Details

Select a transaction to view merchant name, amount, date, status, account, and reference ID.

## Download Statements

1. Open **Statements**.
2. Choose the account and date range.
3. Select **Download PDF** or **Download CSV**.

## Pending Transactions

Pending transactions may change before they post. The final posted amount can differ for tips, holds, refunds, and currency conversion.
