# NovaBank Troubleshooting

> NovaBank is a fictional banking application used for portfolio documentation. It is not a real bank, financial institution, or regulated product.

## Login Problems

Confirm that the email address is correct, reset the password if needed, and check whether two-factor authentication is waiting for approval.

## Failed Transactions

Review the failure message, account balance, recipient details, transfer limits, and network status. Do not retry a transfer repeatedly if the result is unclear.

## Forgotten Password

Use the password reset flow from [Getting Started](getting-started.md). If the reset email does not arrive, wait a few minutes and check spam before requesting another link.

## Verification Problems

Verification may fail because contact information is outdated, the code expired, or too many attempts were made. Request a new code or contact support through the app.

## When to Contact Support

Contact support for suspicious activity, missing funds, locked accounts, identity verification failures, or transactions that show an incorrect final status.
